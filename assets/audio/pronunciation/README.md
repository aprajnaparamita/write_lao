# Audio Files

This directory contains audio files for the Write Lao app.

## Pronunciation Files (`pronunciation/`)

Native Lao speaker recordings for each character.

**Format:** MP3, 44.1kHz, mono, <500KB each
**Naming:** `{codepoint}.mp3` (e.g., `U+0E81.mp3`)

## Sound Effects (`sfx/`)

UI sound effects for feedback.

**Format:** MP3, <500KB each
**Files:**
- `correct.mp3` - Short positive chime (~0.3s)
- `incorrect.mp3` - Short negative buzz (~0.3s)
- `complete.mp3` - Success fanfare (~1s)
- `star.mp3` - Star earned ding (~0.5s)
